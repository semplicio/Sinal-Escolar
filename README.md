Desenvolvido pela [AutomBot](https://autombot.com.br).

## 📥 Download

👉 **[Baixar a versão mais recente](https://github.com/semplicio/Sinal-Escolar/releases/latest)**

Baixe o arquivo **SinalPlayer-Setup.exe** disponível na área de arquivos da versão.

## ✨ Principais recursos

- Agendamentos para um ou vários dias da semana.
- Reprodução de músicas fixas ou aleatórias.
- Bibliotecas separadas nas pastas `Fixa` e `Aleatoria`.
- Seleção da saída de áudio usada pelo sinal da escola.
- Execução em segundo plano sem abrir janelas de terminal.
- Painel de configuração integrado ao aplicativo.
- Inicialização automática opcional com o Windows.
- Ícone na bandeja próximo ao relógio.

## 🛠 Instalação

1. Acesse **[Releases](https://github.com/semplicio/Sinal-Escolar/releases)**.
2. Na versão mais recente, baixe **SinalPlayer-Setup.exe**.
3. Execute o instalador e siga as instruções.
4. Escolha se deseja iniciar o SinalPlayer automaticamente com o Windows.
5. Abra o aplicativo pelo atalho criado na área de trabalho.

O instalador contém os componentes necessários para o funcionamento, incluindo
o PHP incorporado e o VLC Media Player oficial. Não é necessário instalar Python.

## 💻 Requisitos

- Windows 10 ou Windows 11, 64 bits.
- Permissão de administrador durante a instalação.
- Uma saída de áudio disponível.
